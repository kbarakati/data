
# BaTiO₃ (BTO) — AFM/PFM Dataset

## Material Information

- **Material:** Barium Titanate
- **Chemical formula:** BaTiO₃
- **Material class:** Ferroelectric perovskite oxide
- **Characterization:** Atomic Force Microscopy (AFM) / Piezoresponse Force Microscopy (PFM)

## Material Description

Barium titanate (BaTiO₃) is a ferroelectric perovskite oxide exhibiting spontaneous electric polarization that can be switched by an external electric field. Its ferroelectric domains and domain walls exhibit spatially varying electromechanical responses that can be investigated using PFM.

## Data Attribution

- **Operator:** Kamyar Barakati, Boris Slautin, Alla Slautina
- **Research group:** AE-SPM | The University of Tennessee, Knoxville
- **Data source:** Advanced Atomic Design Lab | The Alex Demkov Group

## Dataset Description

This dataset contains approximately seven representative AFM/PFM images of BaTiO₃, selected to illustrate ferroelectric domain structures and spatial variations in material response.
